# AMAZONING — Um país. Muitas realidades.

Repositório de **pré-produção** de um jogo original de ação/aventura 3D single-player, em um mundo semiaberto, numa Terra alternativa. Este pacote consolida o material estabelecido em conversa em 25/10/2026; não constitui roteiro fechado nem jogo executável.

## Comece aqui
1. Leia `AGENTS.md` e `docs/universe/narrative-bible.md`.
2. Consulte `docs/characters/lucas-mazweng.md` e `docs/characters/jeff-a-brasa.md`.
3. Verifique `docs/decisions/decision-log.md` para distinguir fatos aprovados de propostas.
4. No Codex, abra a pasta `AMAZONING` como workspace; peça para ler o `AGENTS.md` e revisar o cânone, sem alterar arquivos.
5. Skills reutilizáveis ficam em `.agents/skills/`.

## Cuidado
As imagens em `assets/concept-art/` são referências oriundas das iterações anteriores. Alguns arquivos mostram versões **superadas** de Jeff, inclusive cabelo preto e detalhes vermelhos. A ficha textual mais recente prevalece: Jeff é LOIRO e usa AZUL/PRETO. Não inferir novos traços a partir de imagens antigas.
